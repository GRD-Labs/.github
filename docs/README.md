## Templates

These are used automatically in every repo in our org (unless a repo has its own).

- [Issue templates](../.github/ISSUE_TEMPLATE/): bug, task and docs
- [Pull request template](../.github/pull_request_template.md)

## In a hurry?

1. Open an issue using one of the templates.
2. Make a small branch from `main`: `feat/12-short-description`.
3. Update the docs in the same PR as your code.
4. Open the PR, tick the checklist, and ask a teammate for a review.

## Something missing or confusing?

These guides are part of our code, so you can improve them the same way: open a `docs/` PR.
